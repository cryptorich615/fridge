# **App Name**: FridgeChef

## Core Features:

- Ingredient Input: Allow users to input ingredients they have available.
- Recipe Generation: Generate recipe suggestions based on the available ingredients, using a Large Language Model as a tool for reasoning about possible recipes, instructions, and ingredient substitutions.
- Recipe Display: Display the generated recipes with clear instructions and ingredient lists.
- Recipe Filtering: Implement a filtering system to refine recipe results based on dietary restrictions or cuisine preferences.

## Style Guidelines:

- Primary color: White (#FFFFFF) for a clean and modern look.
- Secondary color: Light grey (#E0E0E0) for backgrounds and subtle contrasts.
- Accent: Dark grey (#424242) for text and interactive elements.
- Clean and readable sans-serif typography to ensure easy readability of recipes and instructions.
- Use minimalist and modern icons for ingredients and filtering options, with a monochrome aesthetic.
- Clean, single-column layout for easy navigation and readability on all devices.

## Original User Request:
A simple recipe maker that generates recipes based on the ingredients I have in my fridge. Simple UI, nice color scheme.
